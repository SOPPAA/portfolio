# IDEA SPORT Pattani

เว็บไซต์ร้าน IDEA SPORT ปัตตานี รับผลิตเสื้อพิมพ์ลาย เสื้อทีมกีฬา ชุดพละ ชุดตาดีกา รวมถึงงานพิมพ์ลายผ้า ธงโบก และป้ายผ้า
ทำขึ้นเพื่อให้ลูกค้าเห็นตัวอย่างงานจริง ดูราคา และติดต่อร้านได้ในหน้าเดียว โดยเน้นการเปิดดูจากมือถือเป็นหลัก

เว็บที่เผยแพร่อยู่: https://ideasport.pattani.workers.dev/

## หน้าเว็บมีอะไรบ้าง

ทั้งเว็บเป็นหน้าเดียว เลื่อนลงไปตามหัวข้อ

| หัวข้อ | เนื้อหา |
| --- | --- |
| หน้าแรก | โปสเตอร์เด่นของร้าน และกลุ่มลูกค้าที่รับทำ |
| สั่งง่ายใน 4 ขั้นตอน | บอกไอเดีย, ออกแบบ, ยืนยันแบบและไซส์, ผลิตและรับงาน |
| ตัวอย่างผลงาน | รูปงานที่เคยทำ แตะที่รูปเพื่อขยายดู และมีปุ่มไปหน้าแกลเลอรี่เต็ม |
| บริการ | เสื้อพิมพ์ลาย, พิมพ์ลายผ้า ธงโบก ป้ายผ้า |
| ราคา | ตารางราคาตามแบบคอเสื้อและจำนวนที่สั่ง พร้อมเงื่อนไขเพิ่มเติม เช่น แขนยาว และออกแบบฟรีเมื่อสั่งครบจำนวน |
| สไตล์ แบบคอ และชนิดผ้า | ช่วยลูกค้าเลือกแบบ พร้อมลิงก์ไปดูแกลเลอรี่ของแต่ละหมวด |
| แผนที่ | ที่ตั้งร้านและลิงก์ไป Google Maps |
| ติดต่อ | เบอร์โทร, LINE, เฟซบุ๊กเพจ และเฟซบุ๊กส่วนตัว |

หน้าแกลเลอรี่แยกดูตามประเภทคอ ตามสไตล์งาน และตามชนิดผ้า

## เทคโนโลยีที่ใช้

เป็นเว็บสถิต เขียนด้วย HTML, CSS และ JavaScript ล้วน ไม่มีขั้นตอน build และไม่ต้องติดตั้งอะไรเพิ่ม

- ฟอนต์จาก Google Fonts (Prompt, Pattaya, Zen Antique)
- ไอคอนติดต่อจาก Font Awesome Free (สัญญาอนุญาต CC BY 4.0)
- มีโหมดสว่างและโหมดมืด ระบบจำค่าที่ผู้ใช้เลือกไว้ในเบราว์เซอร์
- รองรับมือถือ ที่หน้าจอกว้างต่ำกว่า 551px เมนูด้านบนจะรวมเป็นปุ่ม "คลิกเพื่อดูข้อมูล"

## โครงสร้างโฟลเดอร์

```
.
├── index.html        หน้าเว็บทั้งหมด (โครงหน้า, สไตล์, สคริปต์ และค่าตั้งต้น CONFIG)
├── works.js          รายการรูปผลงานและรูปผ้า
├── img-work/         รูปตัวอย่างผลงานเสื้อและชุดกีฬา
├── images/           รูปที่ใช้ในเว็บ (โปสเตอร์, แผนที่, โลโก้, QR)
│   └── fabrics/      รูปตัวอย่างผ้า
├── og.jpg            รูปที่แสดงเวลาแชร์ลิงก์ลง LINE หรือเฟซบุ๊ก
├── favicon.ico, icon-192.png, apple-touch-icon.png
├── robots.txt
└── sitemap.xml
```

## วิธีแก้ไขข้อมูล

ข้อมูลที่เปลี่ยนบ่อยถูกรวมไว้ให้แก้ง่าย ไม่ต้องไล่หาในโค้ดส่วนอื่น

### เพิ่มรูปผลงาน

1. วางไฟล์รูปในโฟลเดอร์ `img-work/` เช่น `img-work/work-27.jpg`
2. เปิด `works.js` แล้วเพิ่มหนึ่งบรรทัด

```js
{src:"img-work/work-27.jpg",title:"ชื่อที่แสดงใต้รูป",collar:"คอวี",style:"กีฬา"},
```

- `collar`, `style`, `fabric` ใส่ได้ทั้งข้อความเดียวและหลายค่า เช่น `["คอกลม","คอวี"]`
- ถ้าไม่ใส่ รูปจะไม่ขึ้นในหมวดนั้น
- ชื่อหมวดต้องตรงกับที่ตั้งไว้ใน `CONFIG` ของ `index.html`
- รูปหกรูปแรกของรายการจะแสดงในส่วนตัวอย่างผลงานหน้าแรก
- ใน `works.js` มีบรรทัดสำรอง `work-27` ถึง `work-30` ที่คอมเมนต์ปิดไว้ เมื่อรูปพร้อมให้ลบคอมเมนต์แล้วกรอกข้อมูล

ก่อนอัปโหลดรูป แนะนำให้ย่อให้ด้านยาวไม่เกินราว 1,200px และบีบอัดไฟล์ เพื่อให้เว็บโหลดเร็วบนมือถือ

### แก้ข้อมูลร้าน ราคา และหมวดหมู่

เปิด `index.html` แล้วหาส่วน `CONFIG` ซึ่งอยู่ในแท็ก `<script>` ด้านล่างของไฟล์ ในนั้นมี

- ช่องทางติดต่อ: เบอร์โทร, LINE ID, ลิงก์เฟซบุ๊ก
- ที่อยู่ ลิงก์แผนที่ และรูปแผนที่
- รูปโปสเตอร์หน้าแรก
- ชื่อหมวดคอเสื้อ สไตล์ และชนิดผ้า
- ตารางราคา

ส่วนที่อยู่ถัดจาก `CONFIG` เป็นโค้ดที่ทำงานเบื้องหลัง ปกติไม่ต้องแก้

## ทดลองเปิดในเครื่อง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือถ้าอยากให้ใกล้เคียงกับเว็บจริงให้รันเซิร์ฟเวอร์ชั่วคราว

```bash
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000` ในเบราว์เซอร์
